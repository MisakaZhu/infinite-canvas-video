# 新 IP 接入表

首次接入或切换 IP 时读取。先从当前用户指示和私有台账填入已有确认信息，只询问缺项，不要求用户重新填写已提供的资料。下表是可复制模板；实际填写件保存到私有 IP 包版本目录的 `ip-profile.md`，不进入公共技能、Git 或分发包。

## 可复制填写表

| 字段 | 填写内容 |
| --- | --- |
| IP 包 ID / 版本 | 稳定 ip_package_id、ip_package_version |
| 主体角色 ID / 私有称呼 | character_id；多位人物分别登记，不能混用 |
| 授权与来源 | 用户指定使用/跨片复用的消息或资料依据 |
| 身份参考图 | asset_id/version/hash、私有文件路径；区分主参考与辅助参考 |
| 身份图用途与排除项 | 脸部、人物外形；是否明确允许兼作服装/场景参考，未授权则不允许 |
| 配音模型 | 默认 A8；具体任务另有明确要求时记录 |
| 准确音色 | 页面完整名称、可见音色 ID（无则 null）；不得凭近似名称选取 |
| 音频参数 | 当前确认的语速、音调、音量；使用默认值也需记录页面值 |
| 音色认可依据 | 该 IP 的已认可音频/视频资产 ID 与用户确认记录；尚无则填待确认 |
| 人物风格 | 用户明确的人设、语气和动作约束；未知项留空，不从外貌猜测 |
| 表现形式 | 默认边走边说；用户明确指定坐播、访谈、剧情等时记录覆盖范围 |
| 认可样片 | 该 IP 的样片路径/资产 ID、参数快照、认可内容与尚未验证项；没有则待试片 |
| 待补信息 | 缺项及其影响；阻断身份/声音绑定的缺项须在相应生成前补齐 |
| 接入状态 | 待补素材 / 待试片 / 待用户验收 / 样片已认可；附日期与证据 |

## 单条视频绑定（保存在该视频运行记录）

- video_id、run_id、主体 character_id、IP 包 ID 和固定版本、接入表路径。
- 用户口播、分镜、提示词的版本及单视频素材清单；服饰、场景、其他人物不由身份图自动补齐。
- 本次覆盖的表现形式及用户依据；未覆盖时沿用边走边说。人物亲口讲话时仍要求嘴部自然运动，不要求逐字对口型；旁白镜头须有明确稿件/用户依据。
- 每镜记录图片编号→素材 ID/用途，以及音频编号→该角色音色/本镜文案/实际时长。具体合成音频属于单视频素材；音色配置和明确获准复用的样片索引属于 IP 包。
- 提交前回读目标节点的实际引用、完整提示词、模型、时长、比例、分辨率与当前费用。音频与视频分别核对费用，估算不作为实际扣费记录。

## 防止跨 IP 混用

1. 先确定本次 IP 包和角色，再选图片与声音。缺少、找不到或无法唯一匹配时，只暂停依赖该项的生成，可继续整理其他素材；不能沿用上个 IP、上个画布节点的音色或图片。
2. 新 IP 不继承旧 IP 的私人音色名、服饰、已认可结论或人物描述。相同名字不足以证明同一资产，应结合包版本、角色、素材 ID 和用户依据核对。
3. 若复用节点，提交前逐项检查实际引用列表，移除不属于本镜的引用后重新读回编号；不删除原素材、旧节点结果或历史文件。
4. 包升级保留旧版本。已经开工的任务锁定原版本，用户明确换素材后才记录新的任务快照。

## 新 IP 首片验收

在已授权的生成和预算内先验证首个计划片段；适合时可用约 8–12 秒，不强制截断全文或增加一条付费测试。按音频实际长度及模型可用时长配置，额外试片或改稿不自动获授权。

默认先 A8 指定音色生成本镜音频，再图片＋该音频参考生成 Seedance 2.5特价版，禁止视频参考。绑定方法见[音频参考路线](audio-reference-workflow.md)。

验收记录分别列出：人物相似度、指定音色、全文完整性、实际讲话期间的可见嘴部运动、动作/服饰/场景。依据[口播时段验收](speech-activity-qa.md)检查完整讲话时段；不能用解码或抽帧通过代替连续听看。声音与人物的主观相似度由用户认可记录确认，无法核验的项保持待验。

样片被认可后，将原片和认可范围登记到该 IP 包；不重新生成已认可样片。只有用户授权整条或批量制作后才扩展执行。一个 IP 的成功样片不证明其他 IP 或所有镜头已通过。
