# 无限画布视频 Skill

在营销智脑无限画布中，将用户提供的脚本与授权素材制作成人物多场景视频。

首个公开版本：**0.13.0**。

## 核心流程

用户供稿 → IP 身份与音色配置 → A8 指定音色音频 → 图片＋本镜音频参考 → Seedance 2.5特价版 → 逐镜验收 → 剪辑、字幕及无背景音乐成片。

- 默认边走边说，讲话时嘴部自然运动；不要求逐字对口型。用户可指定其他表现形式。
- 禁用视频参考；模型、时长、分辨率和费用以实际页面为准。
- 素材分为单视频一次性使用与 IP 形象复用包；新 IP 不继承其他 IP 的私人配置。
- 用户提供口播、分镜与提示词；不默认重写稿件。
- 剪映只负责后续清晰度提升和音乐。

## 安装与使用

将本仓库下载或克隆到 Codex 的技能目录，文件夹命名为 `infinite-canvas-video`，确保 `SKILL.md` 位于该文件夹根目录。重新载入技能后，在任务中使用 `$infinite-canvas-video`。

需要已登录的营销智脑账号、网站算力，以及可操作当前浏览器的工具。本技能是执行指南，不包含网站账号、API、音色资产或私人素材。

执行前阅读 [技能入口](SKILL.md)。新人物使用 [新 IP 接入表](references/ip-onboarding.md)，已知资料直接填入，实际配置仅存私有工作区。

## 验证边界

一条短样片已获得人物和音色效果认可；其他 IP、长镜头和批量稳定性仍需逐项验证。页面能力与计费会变化，不承诺固定清晰度或成本。

## 隐私与许可

本仓库仅发布通用技能文本，不包含运行记录、参考照片、音视频、个人音色名、租户地址及本地维护历史。

暂未指定开源许可证；公开可读不代表授予额外的开源许可。
