# 素材管理与用途边界

接收、复用、上传及替换素材前阅读。用户声明的用途优先于照片内容与旧模板。人物参考不自动等于服饰、背景或道具参考。

## 两个顶层大类

1. **单个视频一次性使用**（scope=single_video）：按video_id存放本条脚本、分镜、提示词、服饰、场景、其他角色、道具与本视频生成片段。只用于该视频及其修订；不能自动跨视频调用。“一次性”是使用范围，不是一次上传后失效，也不是完成后自动删除。
2. **IP形象复用包**（scope=ip_reusable）：按ip_package_id/version存放用户明确指定跨视频复用的身份/人物外形及其他已明确授权复用的素材。跨视频复用不扩展allowed_uses；身份专用图依然不能提供服饰、场景或声音。

身份、服饰、场景、角色等是大类内部的用途标签，不再作为并列顶层分类。默认将本条视频专用资料归single_video，只有明确指定为IP长期复用或明确准许跨视频使用时才加入IP包；范围有歧义先询问。未收到的素材记待补，不建立虚假文件。单条视频引用IP包的确定版本，不需要复制成另一个身份条目。

每条记录增加scope、video_id（一次性类必填；尚未明确视频时只登记待归属，不能生成）、ip_package_id/ip_package_version（IP类必填）。一次性素材经用户确认升级为复用素材时保存来源关系和新归属记录，不改变历史任务已经固定的版本。更新IP包不自动替换已开工视频的素材快照；切换版本需有明确依据。

## 分类与权威来源

分别管理主体身份（脸部/人物外形）、服饰、场景、其他角色身份、道具、声音、脚本/分镜/提示词、风格参考、生成片段。每个角色有独立character_id；背景海报、照片内路人不自动成为角色。每个文件可有多个明确授权用途，但不得自行扩大用途。

用户指定“只作脸部和人物形象参考”时，只约束该人物的身份与外形，不复制照片中的衣服、鞋袜、饰品、麦克风、场景、背景人物或文字。服饰与场景等待对应的指定素材，不用身份图补缺。后续服饰参考只负责穿着，不用其中模特的脸替换已确认主体。旧模板中的“图1固定身份/服装”仅在该图被明确指定兼作服饰参考时适用。

## 接收与登记

1. 只处理用户给定文件/资料包，保留原文件与原文件名。复制到项目私有素材目录，检查可读性、文件大小、真实类型/尺寸并记录SHA256。不要移动或改写原文件。
2. 为每个素材分配稳定asset_id，记录version、角色/类别、source_path、local_path、hash、用户声明的allowed_uses与excluded_uses、来源消息锚点、接收时间、使用范围、状态与质量备注。缺失值填null，不能编造素材或来源。
3. 同一hash可避免重复保存，但仍分别保留不同任务/用途的登记；不同hash即使同名也不得覆盖，建立新版本并注明replaces_asset_id。旧版本保留，替换须由用户明确指定或确认。
4. 资料包在新的唯一接收目录中展开，核对清单。拒绝绝对路径、上级路径穿越或链接导致的越界展开；不运行包内程序。先按用户清单分类，不根据文件名猜人物归属或授权。
5. 裁剪、去背景、压缩、增强等派生文件另存，记录parent_asset_id和实际处理；不得把派生图当成用户原图，也不在未要求时自动美化。原图可读不等于已适合模型，质量不足先说明具体问题。

## 每条视频的引用清单

在任务私有checkpoint中固定script_version、shot_id、asset_id/version/hash、实际图片/视频编号、用途、目标节点与上传/引用状态。通用素材库登记与单条任务使用清单分开；不能把全库图片一次性全部上传，也不因接收素材而立即付费生成。

实际绑定后读取缩略图、编号与已引用状态。编号是本次节点的编号，不是asset_id；换模型、增删引用后重新核对。身份、服饰和其他角色映射不清时先询问，不替用户猜测。收到服饰等补充包后沿用现有身份素材的asset_id，不重新绑定为新人物。

默认不重写用户分镜/提示词。绑定素材并配置参数时遵守素材用途；如果原提示词明确要求复制身份图服装，却与用户的“身份专用”声明冲突，指出冲突并请用户确认所需修正，不静默改稿或沿用错误服饰。普通引用编号的无损调整按SKILL.md执行并记录。

## 存储与恢复

私人原片、肖像、聊天、脚本、路径和运行记录放项目local/runs/outputs等明确忽略的目录。公共skill与项目规范只保留通用管理规则；不加入具体人物姓名、家庭关系、租户、私人路径或真人素材。发布前同时核对Git跟踪清单与ZIP条目，gitignore不是已跟踪文件的保密保证。

接收、已确认用途、待补件、已上传、已引用、已用于生成、已被替代是不同状态，分别记录。缺少服饰/场景/其他角色的pending槽位不建立虚假文件条目；后续到件后关联实物并更新状态。恢复按asset_id、版本与hash定位，不按“最新图片”猜。只有用户明确要求才清理源素材或历史版本。

## 新 IP 接入

首次接入或切换 IP 使用[新 IP 接入表](ip-onboarding.md)，填写件放私有 IP 包版本目录；每条视频锁定包版本并记录逐镜角色与音色映射。公共模板不保存真实身份、音色名或文件路径。
