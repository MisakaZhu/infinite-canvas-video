# 指定音色：先A8音频，再图片＋音频生视频

## 当前默认与证据

指定音色人物口播采用：用户确认文案 → A8指定音色配音 → 人物/场景图片＋本镜音频 → Seedance 2.5特价版 → 原片试听与说话动作检查 → 营销智脑剪辑与字幕。禁止视频参考。后期换声不再是默认路线。

2026-10-01实测：3张图片＋1段已认可的A8口播，8秒、720p、9:16，节点显示70算力/秒，估算560算力；引用音频后页面费率未上涨，实际扣费未核验。生成原片8.064秒、720×1280、24fps，完整解码通过，密集帧可见嘴部变化；未替换音轨，用户试听后明确认可该声音和样片效果。该样片可作为当前私有项目的验收基准，不代表任何音色/长镜头/多场景都必然成功，不是严格逐字口型已验证。

## 执行步骤

1. 读取当前IP包与任务确认的音色准确名称、A8模型、文案版本。公共技能不硬编码个人音色或姓名；已有确认配置直接复用，不重复索取。音色资产可归IP复用包；本镜生成的口播音频按内容归单视频素材。
2. 在音频节点用A8及指定音色生成本镜完整文案；已有对应已确认音频直接复用。核对文字、声音选择、实际音频长度和输出归属。语速/音调按已确认配置，不为挤进短镜头擅自加速或删字。
3. 视频节点选Seedance 2.5特价版。通过“添加视频引用 → 画布”选择对应音频“添加引用”，也可上传已确认音频文件。按钮名含“视频”不意味着必须用视频。检查弹窗“已引用”和节点的“音频1”缩略图；只有上传或画布连线不够。
4. 同时核对图片1/2/3等用途与音频1归属。引用列表必须无视频。保存实际编号、素材ID、音频文案、声音模型/名称和时长；不以文件排序或画布位置推断编号。
5. 视频时长容纳完整音频及必要前后动作；本次6秒左右配音用了8秒视频，此数值仅为示例，不能套用所有镜头。核对该模型当前分辨率、比例及费率；音频参考和视频参考分别核价，不能把视频参考涨价直接套到音频。按实际页面算整镜估价，实扣另记。
6. 保留用户创作稿；落实已授权音频路线时移除“生成声仅占位、最终另配指定声音”等冲突执行说明，记录适配差异。提示词指明音频编号、声音来自画面人物、保持音色/语气/节奏/完整文案，人物讲话起止与停顿跟随音频；讲话期间嘴部可见、自然开合。无背景音乐，不另添对白。
7. 本次正常生成按已有授权提交一次。陌生音色/新实现路线先在计划内首段验证，不擅自增加付费测试。明确失败或音色不符保留记录；没有再次付费授权不重试，不静默转回占位声后配音。
8. 先检查未经换轨的生成原片。逐句检查文案完整、无双重人声/额外音乐、人物讲话期间嘴部动作，再由可听音的工具或用户确认声音相似度。波形不同不等于音色不同；波形相似或媒体解码通过也不能单独证明音色和口型合格。接受结论与用户原话记录到私有任务，既有认可样片作为后续比较基准。
9. 已获认可的原片保留其音轨进行剪辑、字幕和无音乐交付。后期替换音轨只在用户明确选择的修复任务中使用，并遵循speech-activity-qa.md，不自动覆盖本路线产物。

## 受托适配时的声音提示

> 音频1是本镜唯一口播声音参考，保持其音色、语气、节奏和完整对白。参考人物自然缓步行走，面向镜头亲口说出：“【本镜确认文案】”。讲话起止和停顿跟随音频1，嘴唇与下颌持续自然运动，嘴部清楚可见。声音来自画面人物，不能变成画外旁白；不能讲话时闭嘴、吃东西、背身或切走。不添加其他对白或背景音乐。

此模板用于已授权技术适配，不授权更改用户文案、服饰、动作或分镜创意。
