本文件仅作教程来源说明。当前用户要求默认使用Seedance 2.5特价版、不要Wan、人物边走边说且嘴部自然运动；以下历史模型与示例不授权使用Wan或交付旁白版。实际执行以SKILL.md和live-execution.md为准。

## 示例映射与参数

最终可见图序：1 人物多视角参考；2 店门与排队；3 店内；4 一桌火锅菜；5 菜品特写。五张图片是示例数量，不是平台限制。角色姓名、身高、衣着、餐馆与对白均属演示内容，不成为新任务的默认要求。

约 49 秒曾显示 Seedance 2.5 生视频、480P、10s、9:16；约 63–66 秒最终显示 Wan 3.0、wan3.0 / 720P / 30s / 3:4 / 开启，以及 40算力/秒。“开启”的选项名称没有展开，不能断言是音频开关或固定启用；运行时展开看真实字段。

录屏在不同片段出现 不同的画布项目地址，且参考图和参数发生变化，说明教程有演示切换。不能把这些 ID 当同一真实任务，不复制到运行 checkpoint。

## 复用边界

已纳入本技能的通用原则：用户指定后台入口、独立运行/标签绑定、可见 UI 操作、输入输出归属、受理/生成/预览/文件验证分开、禁止因下载失败重复生成。这些已写入新技能，不依赖旧技能文件仍存在。

没有照搬：一键追爆链路、数字人音频、道商人设、五个话题、无音乐与音量、右侧智能包装历史的固定入口、旧技能的特殊下载授权标记。新技能下载依据本次用户任务授权及工具权限；不声称旧技能专属授权自动扩展。

录屏未演示：下载按钮、工作流模板保存、批量执行、完整等待与错误处理。相应恢复/交付指导是通用方法迁移，执行时必须以实际 UI 为准，不得宣称已由录屏验证。
